AMOffline (Windows)
===================================

Install (recommended)
  1. Right-click AMOffline-Windows.zip and choose "Extract All...".
  2. Open the extracted AMOffline folder and double-click "Install AMOffline.cmd".
     If Windows asks whether to run it, choose Run (or More info > Run anyway).
  AMOffline is added to the Start menu and the desktop, and opens straight away.
  No administrator rights are needed, and Java is included.

Uninstall
  Settings > Apps > Installed apps > AMOffline > Uninstall.

Your appointments are saved automatically in your user folder, in AMOffline
(for example C:\Users\<you>\AMOffline). Backups go in AMOffline\Backups.
Uninstalling does not delete your appointments.

Run without installing
  Open a Command Prompt in this folder and run:
      runtime\bin\javaw.exe -jar app\AMOffline.jar
