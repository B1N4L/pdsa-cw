AMS - Appointment Manager (Windows)
===================================

Install (recommended)
  1. Right-click AMS-Windows.zip and choose "Extract All...".
  2. Open the extracted AMS folder and double-click "Install AMS.cmd".
     If Windows asks whether to run it, choose Run (or More info > Run anyway).
  AMS is added to the Start menu and the desktop, and opens straight away.
  No administrator rights are needed, and Java is included.

Uninstall
  Settings > Apps > Installed apps > AMS Appointment Manager > Uninstall.

Your appointments are saved automatically in your user folder, in AMS
(for example C:\Users\<you>\AMS). Backups go in AMS\Backups.
Uninstalling does not delete your appointments.

Run without installing
  Open a Command Prompt in this folder and run:
      runtime\bin\javaw.exe -jar app\AMS.jar
